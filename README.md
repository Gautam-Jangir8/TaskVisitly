# TaskVisitly
TaskCisitly is a full-stack web application for managing users. It is built using Spring Boot, Hibernate, REST API, Cloudinary, OAuth2,  and MySQL on the backend, and Thymeleaf, Bootstrap, and JavaScript on the frontend.It and provides a practical implementation of core Java backend development concepts.

# Features
* User Registration and Login System: Allows users to register and log in securely.
* Add, Edit, and Delete Contacts: Users can create, update, and remove contact information as needed.
* Paginated Contact List: Displays contacts in a paginated format for better navigation.
* Profile Management: Users can update their personal profile details.
* Responsive Design with Bootstrap: Ensures the application is mobile-friendly and works seamlessly across devices.
* Secure Authentication with Spring Security: Implements secure login mechanisms to protect user data.
* Some Secured URLs: Accessed only if user is valid.
* Cloudinary Storage: Instead of Storing images locally, stored in cloud.
* Login By Google: Saves time, If user is already verified by google, no need to verify.
* Export user details in Excel: Export the user details in Excel file.
* Filter Feature: Filter the User details based on Name, Email, Contact, Or find user by specific Phone Number.
* Dark/ Light Mode: Visual performance tends to be better with light mode, whereas some people with cataract and related disorders may perform better with dark mode.
  
# Tech Stack
# Backend:
* Java: The core programming language used to build the application.
* Spring Boot: Provides a robust framework for building RESTful APIs and managing application dependencies.
* Hibernate: Simplifies database operations with object-relational mapping (ORM).
* MySQL: Serves as the relational database to store user and contact data.
* Spring Security: Adds security layers for authentication and authorization.

# Frontend:
* Thymeleaf: A template engine for rendering dynamic content on the web pages.
* Bootstrap: Ensures a responsive and modern UI design.
* JavaScript: Adds interactivity and dynamic behavior to the frontend.
* HTML/CSS: Provides the structue and styling of the application.
